PENGGUNAAN

Dua belas modul produksi konten AI — dari merakit karakter sampai membedah video kompetitor. Panduan ini menjelaskan cara pakai tiap modul, cara merantai modul satu ke lainnya, dan trik-trik biar hasilnya konsisten. Semua proses berjalan lokal di browser kamu: tanpa server, tanpa upload, tanpa menunggu.

MULAI DARI DASAR ↓
BAGIAN 00

Dasar Aplikasi

00.1Membuka Modul

  1. Buka situs — tunggu intro countdown 3-2-1 selesai (atau klik untuk melewati).
  2. Di halaman indeks, arahkan kursor ke modul untuk membaca deskripsi singkatnya.
  3. Klik modul mana pun untuk masuk ke ruang kerja. Tekan ESC kapan saja untuk kembali ke indeks.

00.2Ruang Kerja

  1. Panel kiri — PARAMETER: semua pilihan yang membentuk konsep (dropdown, slider, chip).
  2. Panel kanan — HASIL: dokumen output yang ter-update langsung setiap kamu mengubah parameter. Tidak ada tombol "generate" — semuanya live.
  3. Di layar HP, dua panel berubah jadi tab di bawah layar: PARAMETER dan HASIL.
  4. Tekan ROLL di bagian bawah panel kiri untuk mengacak semua parameter sekaligus — cara tercepat mencari ide baru.

00.3Menyimpan Hasil

  1. SALIN — menyalin satu prompt ke clipboard.
  2. SALIN SEMUA — menyalin seluruh dokumen (prompt + script + catatan).
  3. UNDUH .TXT — mengunduh dokumen sebagai file teks.
  4. SIMPAN TAKE — mengarsipkan ke riwayat. Buka lewat ikon riwayat di pojok kanan atas; tersimpan di perangkat kamu sendiri.
Menyalin prompt otomatis ikut menyimpan TAKE — jadi semua ide yang sudah kamu pakai tidak pernah hilang.
BAGIAN 01

Istilah Penting

IstilahArtinya
Master PromptPrompt inti yang menyimpan identitas (karakter/scene). Simpan baik-baik — ini "kunci" konsistensi antar-gambar.
Negative PromptDaftar hal yang harus dihindari AI (tangan cacat, watermark, dll). Tempel di kolom negative pada tool tujuan.
TAKESatu versi hasil yang diarsipkan. Istilah pinjaman dari dunia film: "take satu, take dua…"
TimecodeFormat waktu JJ:MM:DD:FF (jam:menit:detik:frame). Dipakai di script supaya timing presisi.
Format outputBentuk akhir prompt: Midjourney (dengan parameter --ar), SDXL (dengan resolusi), Flux (kalimat natural), atau Umum.
BAGIAN 02 · GRUP A

Modul Karakter

01Character Generator

Kapan dipakai: saat butuh karakter AI baru dari nol — untuk konten, campaign, atau drama.
  1. Isi nama karakter (kosongkan kalau mau dibuatkan, atau tekan ROLL).
  2. Pilih gender, usia, dan etnis — deskripsi etnis sudah diterjemahkan ke bahasa prompt otomatis.
  3. Tentukan rambut, outfit, dan ekspresi.
  4. Pilih lokasi, pencahayaan, dan angle kamera — tiga hal ini yang paling menentukan mood foto.
  5. Pilih rasio (9:16 untuk TikTok/Reels, 1:1 untuk feed) dan format output sesuai tool gambar yang kamu pakai.
  6. Salin MASTER PROMPT → tempel di Midjourney / Stable Diffusion / Flux.
  7. Butuh variasi angle untuk karakter yang sama? Gunakan 3 PROMPT TURUNAN — wajah dan outfit tetap, hanya angle yang berubah.
Simpan MASTER PROMPT di catatan. Untuk konsistensi wajah antar-gambar, pakai fitur referensi: --cref di Midjourney, IP-Adapter/PuLID di SDXL, atau referensi Flux.

02Character Clone

Kapan dipakai: saat sudah punya gambar karakter dan mau memakainya berulang di berbagai konten.
  1. Unggah gambar referensi — sistem otomatis membaca 5 warna dominan sebagai palet. Semua diproses lokal, gambar tidak dikirim ke mana pun.
  2. Isi fitur yang wajib terkunci sedetail mungkin: bentuk wajah, tahi lalat, model rambut, senyum khas. Makin detail, makin kuat kuncinya.
  3. Pilih aspek yang boleh divariasikan (pose, outfit, latar, dst).
  4. Salin CHARACTER LOCK PROMPT dan gunakan bersama gambar referensi di tool gambar kamu.
Palet warna yang terekstrak bisa jadi acuan grading feed — konsistensi warna = feed terlihat profesional.

03Character Modifier

Kapan dipakai: saat karakter sudah ada tapi butuh diubah sebagian — tanpa merakit ulang dari awal.
  1. Tempel prompt lama karakter kamu di kolom paling atas.
  2. Pilih aspek yang diubah (outfit, ekspresi, pose, dll).
  3. Tulis detail perubahan dengan bahasa sehari-hari, misal: "ganti jadi jas hitam, ekspresi menahan tangis".
  4. Atur intensitas: angka kecil = perubahan halus, angka besar = perubahan drastis.
  5. Untuk perubahan kecil pakai DELTA PROMPT; untuk perubahan besar pakai FULL PROMPT.
BAGIAN 03 · GRUP B

Modul Gambar & Prompt

04Image Generator

Kapan dipakai: bikin gambar AI apa pun dengan pilihan yang sudah disederhanakan.
  1. Tulis ide gambar sebebas mungkin — bahasa Indonesia pun boleh.
  2. Tekan PERKAYA PROMPT — sistem otomatis menambah 3 lapis detail teknis ke idemu.
  3. Atur arah visual: gaya, mood, waktu, lensa, komposisi, pencahayaan.
  4. Output memberi 1 master prompt + 3 arah pengembangan (lebih sinematik / editorial / dramatis). Coba semuanya, bandingkan hasilnya.

09Prompt Siap Pakai

Kapan dipakai: butuh inspirasi cepat tanpa menyusun prompt sendiri.
  1. Cari dengan kata kunci atau filter per kategori (karakter, potret, sinematik, produk, fashion, lanskap, 3D, makanan).
  2. Klik judul untuk membuka prompt lengkapnya.
  3. SALIN apa adanya, atau KIRIM KE IMAGE GENERATOR untuk dikembangkan lebih jauh dengan pengaturan lengkap.
32 prompt ini ditulis dengan struktur yang teruji. Pelajari polanya — lalu modif untuk kebutuhanmu sendiri.
BAGIAN 04 · GRUP C

Modul Konten & Promosi

05AI Influencer Maker

Kapan dipakai: membangun persona influencer AI yang utuh — bukan cuma wajah.
  1. Pilih niche dan persona — keduanya menentukan seluruh karakter visual.
  2. Simpan FACE MASTER PROMPT — ini identitas tetap. Setiap generate ulang, bagian ini tidak boleh berubah.
  3. Gunakan TEMPLATE PROMPT HARIAN untuk konten rutin: tinggal ganti bagian aktivitas & lokasi.
  4. Ikuti ritme posting 7 hari dan 6 ide konten pembuka yang sudah disusun.
Aturan emas: generate wajah SEKALI, simpan sebagai referensi, lalu variasikan hanya pakaian/lokasi/aktivitas. Palet feed dijaga dengan grading seragam.

06UGC Content

Kapan dipakai: konten jualan gaya "dibuat orang biasa" — untuk produk sendiri atau affiliate.
  1. Isi nama produk dan masalah yang diselesaikannya — tulis masalahnya sejujur mungkin, di situlah kekuatan UGC.
  2. Pilih durasi (15s / 30s / 60s) dan tone.
  3. Rekam mengikuti script ber-timecode — tiap segmen sudah ada narasi + visualnya.
  4. Uji dulu 3 pilihan hook — rekam ketiganya, unggah yang paling kuat menahan scroll.
  5. Salin caption + hashtag yang sudah disiapkan.

11Ads Maker

Kapan dipakai: butuh konsep iklan yang terukur — bukan sekadar "jualan keras".
  1. Isi produk, tujuan iklan (awareness / konversi / traffic), dan offer.
  2. Tulis pain point audiens — makin spesifik, makin terasa "ini gue banget".
  3. Pelajari 3 sudut psikologis (sakit / bukti / geliat) lalu pilih satu untuk dieksekusi.
  4. Rekam sesuai script timecode, gunakan headline terkuat dari 5 pilihan.
A/B test: jalankan dua sudut berbeda dengan budget kecil 3–4 hari, matikan yang kalah. Pastikan hanya HOOK yang berbeda — variabel lain harus sama.
BAGIAN 05 · GRUP D

Modul Video & Ekstraksi

07Drama Pendek V2

Kapan dipakai: bikin drama pendek utuh — dari ide sampai dialog per scene.
  1. Langkah 1 — Ide: pilih genre, tone, durasi, dan platform.
  2. Langkah 2 — Karakter: isi tokoh utama, profesi, penentang, dan orang terdekat.
  3. Langkah 3 — Struktur: pilih template cerita, jumlah scene, dan latar. Tekan RENDER HASIL.
  4. Kamu dapat production bible mini: logline, character sheet, dan breakdown per scene — lengkap dengan aksi, dialog, usulan shot, durasi, dan prompt visual siap generate.
Kunci wajah tokoh dulu dengan Character Generator SEBELUM render scene — wajah yang berubah antar shot adalah pembunuh utama drama AI.

08Music Clip V2

Kapan dipakai: video musik AI yang potongannya jatuh tepat di beat.
  1. Isi judul, genre, mood, durasi, dan BPM lagu kamu (BPM bisa dicek di aplikasi musik apa pun).
  2. Pilih konsep: performa+naratif / one-take / metafora visual / storyline.
  3. Shotlist otomatis dipetakan ke beat dan bar — kamu akan tahu potongan harus jatuh di detik ke berapa.
  4. Di aplikasi editing, pasang marker setiap N beat sesuai spesifikasi, lalu selaraskan shotlist ke marker.

10Scene Extractor

Kapan dipakai: membedah video (misal milik kompetitor) untuk dipelajari strukturnya.
  1. Unggah video — MP4/WebM/MOV. Video diproses 100% lokal di browser, tidak pernah diunggah ke server mana pun.
  2. Atur sensitivitas deteksi: rendah untuk cut keras saja, tinggi agar transisi halus ikut terdeteksi.
  3. Tekan DETEKSI SCENE — sistem membandingkan piksel antar frame untuk menemukan pergantian shot.
  4. Pelajari hasilnya: jumlah scene, durasi rata-rata, cut per menit, dan klasifikasi irama (tenang/sedang/cepat).
  5. Salin laporan timecode atau unduh keyframe tiap scene.

12Frame Extractor

Kapan dipakai: mengambil frame penting untuk storyboard, referensi warna, atau bahan produksi.
  1. Unggah video, lalu pilih mode: MERATA (sejumlah frame dibagi rata) atau INTERVAL (satu frame tiap N detik).
  2. Tekan EKSTRAKSI FRAME.
  3. Klik gambar untuk memperbesar, unduh satu-satu atau semuanya sekaligus.

BAGIAN 07

Tanya Jawab

Apakah video/gambar saya aman?
Sangat aman. Semua file diproses lewat Canvas API langsung di browser kamu — tidak ada satu byte pun yang dikirim ke server.
Kok hasil kosong / tidak berubah?
Pastikan kolom wajib sudah terisi (misalnya "ide gambar" di Image Generator). Output selalu ter-update live — tidak ada tombol generate.
Kok ikon tidak muncul?
Ikon dan font dimuat dari internet saat pertama kali dibuka. Tanpa koneksi, aplikasi tetap berfungsi penuh — hanya tampilan ikon/font yang memakai cadangan sistem.
Riwayat TAKE saya hilang setelah ganti HP?
TAKE tersimpan di localStorage per browser per perangkat. Salin dokumen penting ke .TXT sebelum pindah perangkat.
Prompt ini dipakai di tool AI mana?
Output mendukung Midjourney (--ar otomatis), Stable Diffusion/SDXL (resolusi disertakan), Flux, dan format umum. Pilih "Format output" sesuai toolmu.
Gratis?
100% gratis, tanpa akun, tanpa batas pemakaian.
