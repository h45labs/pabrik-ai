<h2>🚀 Demo</h2>

<h2>💻 Menjalankan Secara Lokal</h2>

<p>Tidak ada build step, tidak ada dependensi yang harus di-install:</p>

<pre><code>git clone https://github.com/h45labs/pabrik-ai.git
cd pabrik-ai</code></pre>

<p>Lalu buka <code>index.html</code> di browser — selesai.<br>
Atau cukup download repo, lalu double-click <code>index.html</code>.</p>

<h2>🔒 Privasi</h2>

<ul>
<li>Video dan gambar diproses lewat <strong>Canvas API di browser</strong> — tidak pernah dikirim ke server mana pun</li>
<li>Riwayat TAKE tersimpan di <code>localStorage</code> perangkat sendiri</li>
<li>Koneksi internet hanya dibutuhkan untuk font (Google Fonts) dan ikon (Lucide CDN) — tanpa internet, aplikasi tetap berfungsi</li>
</ul>

<h2>🛠️ Teknologi</h2>

<ul>
<li><strong>HTML5 + CSS3 + Vanilla JavaScript</strong> — satu file, tanpa framework, tanpa build step</li>
<li><strong>Canvas API</strong> — ekstraksi frame, deteksi scene berbasis perbandingan piksel, analisis palet</li>
<li><strong>localStorage</strong> — arsip riwayat take</li>
<li><strong>Font:</strong> Anton · Archivo · JetBrains Mono</li>
<li><strong>Ikon:</strong> Lucide</li>
</ul>
